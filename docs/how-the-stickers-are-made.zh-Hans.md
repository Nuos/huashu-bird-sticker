# 贴纸是怎么生成的

[English](how-the-stickers-are-made.md)

写给想用生图模型做类似东西的人，简单说说做法。贴纸由AI生成，审核也用AI，这不等于专家核对。方法中途改过几次，这里写的是现在的做法。

## 一个循环

1. **写一张简短的特征卡**：和最像的近缘种怎么区分、喙、腿脚、关键比例。
2. **找参考照片。**有合适的照片时，让模型参考鸟的样貌；提示词要求不照搬照片里的姿势。
3. **生成**：用GPT-image。多数鸟按同一种图鉴版式画：头朝左、侧身、翅收拢、双脚平踩一条看不见的地面线、浅灰纯色背景；浮水、飞行等特殊类群另定姿势。
4. **审核**：另一个模型按辨识、羽色、喙眼、腿脚、比例五项打0–4分。五项都≥3、辨识=4、而且能放进野外图鉴当图版，才算过线。
5. **还要继续生成时**，要求审核提出1–3条修正要点，放进下一轮提示词；如有冲突，提示词要求以修正为准。过线后抠图、需要时放大，并在元数据里标明AI生成。

## 提示词案例

## 我们的几条经验

- **写具体，包括理所当然的部位。**我们的经验是「尾约占全长四成」比「长尾」管用；没写的部位容易被画成「一般的鸟」：细长粉腿、雀形目的脚、尾长靠猜。
- **姿势自己定，脚踩地面。**照搬照片姿势时，有些图会画成背面或飞行，辨识特征被挡住；在一组试验中，让脚「握一根看不见的树枝」时，很多图画成悬空张爪；因此站姿改为双脚平踩一条看不见的地面线。
- **审核意见写成能直接放进提示词的句子。**比如「露出的跗跖约是喙长的两倍」，而不是「腿不对」。

## 局限

图和审核都是AI做的，有些错只有懂这些鸟的人才看得出来。熟悉某一科的话，欢迎[帮忙审一个科](../../../issues/new?template=family-review.yml)；看到画错的，请[报告给我们](../../../issues/new?template=sticker-error.yml)。贡献者名单见[CONTRIBUTORS.md](../CONTRIBUTORS.md)。
